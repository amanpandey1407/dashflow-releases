[ ARCHITECTURE ]

Core capabilities

Engineered for stability, predictable throughput, and minimal system resource usage.

01 • MULTI-STREAM ENGINE

Multi-Stream Acceleration

Splits incoming files into concurrent byte-range connections. Each stream downloads simultaneously, saturating connection bandwidth and bypassing single-connection server throttling.

02 • SOCKET BALANCING

Real-Time Socket Rebalancing

When an individual connection slows down or encounters latency, idle sockets dynamically take over unfinished byte ranges to ensure balanced, prompt completion.

03 • EXTENSION

One-Click Browser Interception

The companion Chromium extension intercepts download links directly from Chrome, Edge, Brave, and Opera, passing them seamlessly to the desktop manager.

04 • VIDEO DOWNLOADS

Video Downloads via Extension

Get any video downloaded directly with the extension. Easily capture streaming web videos right from your browser without third-party converters.

05 • RESUME & INTEGRITY

Checkpoint Resume & Recovery

Interrupted or paused downloads resume from exact byte checkpoints without restarting transfers or corrupting files on disk.

06 • QUEUE

Queue & Bandwidth Limits

Manage multiple downloads with priority queuing and optional speed limits to maintain responsive network performance for other applications.

[ SECURITY, PRIVACY & EXTENSION PERMISSIONS ] 🔒 100% CLEAN • ZERO MALWARE • LOCAL ONLY

DashFlow is engineered on a strict Local-First Architecture. All file downloads, personal credentials, and browsing links stay strictly on your computer. The browser extension communicates solely with your local desktop application (http://127.0.0.1:9527). DashFlow is 100% free of viruses, adware, toolbars, and cryptocurrency miners.

downloads
Intercepts browser file downloads and hands them over to DashFlow's parallel multi-stream acceleration engine.
webRequest
Detects downloadable file extensions and MIME headers (.zip, .exe, .iso, .mp4) to trigger the pre-download prompt.
cookies
Securely forwards session authentication to DashFlow's local media engine so you can download high-resolution streams you have access to.
contextMenus & notifications
Adds "Download with DashFlow" to the right-click menu and alerts you when large background downloads complete.
